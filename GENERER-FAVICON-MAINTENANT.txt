✨ ÉTAPE 1 : Ouvrir le générateur
═══════════════════════════════════════════════════════════════

Double-cliquez sur ce fichier :
   generate-favicon-now.html

Il s'ouvrira dans votre navigateur par défaut.

═══════════════════════════════════════════════════════════════

⏳ ÉTAPE 2 : Attendre le chargement automatique
═══════════════════════════════════════════════════════════════

Le logo va se charger automatiquement depuis public/logo.jpg

Vous verrez :
✅ Message "Logo chargé avec succès"
✅ Aperçu du favicon en 3 tailles (16px, 32px, 48px)
✅ Bouton "Télécharger favicon.ico" activé

═══════════════════════════════════════════════════════════════

⬇️ ÉTAPE 3 : Télécharger le favicon
═══════════════════════════════════════════════════════════════

Cliquez sur le bouton :
   📥 Télécharger favicon.ico

Le fichier sera téléchargé dans votre dossier "Téléchargements"

═══════════════════════════════════════════════════════════════

📂 ÉTAPE 4 : Remplacer l'ancien favicon
═══════════════════════════════════════════════════════════════

1. Allez dans votre dossier Téléchargements
2. Copiez le fichier "favicon.ico"
3. Collez-le dans :
   c:\Users\PLC\Downloads\lovable-2f588b4d (1)\public\

4. Remplacez l'ancien fichier si demandé

═══════════════════════════════════════════════════════════════

🔄 ÉTAPE 5 : Redémarrer le serveur
═══════════════════════════════════════════════════════════════

Dans PowerShell :
   cd "c:\Users\PLC\Downloads\lovable-2f588b4d (1)"
   
   # Arrêter le serveur (Ctrl+C si déjà lancé)
   # Puis relancer :
   bun run dev

═══════════════════════════════════════════════════════════════

✅ ÉTAPE 6 : Vérifier
═══════════════════════════════════════════════════════════════

Ouvrez votre navigateur :
   http://localhost:3000

Vérifiez l'onglet du navigateur pour voir le nouveau favicon !

⚠️ Si le favicon n'a pas changé :
   - Fermez TOUS les onglets du site
   - Videz le cache : Ctrl + Shift + R
   - Testez en navigation privée

🎉 TERMINÉ !

Votre nouveau favicon est maintenant actif !

❓ Problèmes ?
═══════════════════════════════════════════════════════════════

Si le logo ne se charge pas automatiquement :
   1. Le fichier HTML propose un upload manuel
   2. Cliquez sur "Choisir un fichier"
   3. Sélectionnez public/logo.jpg
   4. Continuez à partir de l'étape 3
