## 💡 Astuces

### Modifier la taille du logo
```tsx
// Trop grand ? Réduisez h-10 → h-8
<img src="/logo.jpg" className="h-10" />

// Trop petit ? Augmentez h-8 → h-12
<img src="/logo.jpg" className="h-8" />
```

### Vider le cache du favicon
```
1. Ctrl + Shift + R (hard refresh)
2. Ou fermez tous les onglets et rouvrez
3. Ou testez en navigation privée
```

### Voir tous les commits
```powershell
git log --oneline --graph
```

### Annuler le dernier commit (non pushé)
```powershell
git reset --soft HEAD~1
```

## 🐛 Support

### Problèmes courants

**Logo ne s'affiche pas** :
- Vérifiez : `public/logo.jpg` existe
- Cache navigateur : Ctrl + Shift + R
- Redémarrez le serveur

**Favicon ne change pas** :
- Fermez TOUS les onglets
- Videz le cache navigateur
- Navigation privée pour tester

**Push GitHub échoue** :
- Authentification : `gh auth login`
- Pull d'abord : `git pull origin master`
- Résolvez les conflits
